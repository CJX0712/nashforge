# NashForge 模型卡（Model Card）

作者：晨星。· 版本：0.1.0。

---

## 模型细节

- **类型**：不完美信息二人零和扩展式博弈的 Nash 均衡求解器。
- **精确方法**：Koller-Megiddo-von Stengel 1996 序列式线性规划（实现权重序列式 LP，对偶增广双 LP）。
- **近似方法**：Zinkevich 2007 CFR / Tammelin 2014 CFR+（纯 numpy，chance-sampling tabular）。
- **基准博弈**：Kuhn poker（n 张牌泛化，默认 n=3）。

---

## 预期用途

- **用途**：求解小规模不完美信息博弈的精确/近似 Nash 均衡；教学与研究博弈论均衡算法；
  作为更大规模求解器（如 CFR+ 在大幅博弈上的预热/校验 oracle）。
- **超出范围**：非大规模博弈（如无限注 Texas Hold'em 完整树）；非二人零和；
  非完美回忆博弈（序列式表达要求完美回忆）。

---

## 训练 / 求解数据

- 无外部训练数据。博弈规则由 `games/kuhn.py` 确定性定义；CFR/CFR+ 的“学习”仅来自
  自我博弈采样，不依赖任何离线数据集。

---

## 评估指标

| 指标 | 定义 | 目标 |
|------|------|------|
| 可剥削性（exploitability） | `BR0 + BR1`（Nash 处 = 0） | 精确 oracle ≈ 0；CFR+ 随迭代 → 0 |
| 博弈值 | 玩家 0 视角期望收益（零和 ⇒ 第二项取负） | 与范式 LP 锚点一致 |
| 强对偶残差 | `|oracle_v_p0 − oracle_v_p1|` | < 1e-16 |
| 收敛轮次 | 可剥削性首次跌破 `exploit_eps` 的迭代 | n=3 CFR+ ≈ 16130 |
| 确定性 | 同 seed 两次运行策略差异 | 逐位一致（≤ 1e-12） |

---

## 评估结果（n=3，默认配置）

- **G1 精确 oracle**：`exploit = −5.55e-17`，`|v − LPanchor| = 0`，`|v_p0 − v_p1| = 8.33e-17`。
- **G2 收敛**：best seed final exploit ≈ 0.0079 < `1e-2`；cross_iter ≈ 16130 ≤ 24000。
- **G3 多 seed 基线**：mean CFR+ exploit ≈ 0.0094 ≪ uniform 基线 0.7500。
- **G4 确定性**：oracle 重算一致；CFR+ 同 seed 两轨迹逐位一致。
- **端到端**：`run_pipeline` 全部门禁通过，wall ≈ 42s（≤ 60s 预算）。
- **标准结果**：博弈值 = −1/18（与 Kuhn 1950 一致）。

---

## 局限与风险

- **规模**：序列式 LP 的变量数为序列数，随博弈树指数增长；当前验证覆盖 n=2..5（Kuhn），
  仅适用于教学/研究规模的不完美信息博弈。
- **泛化**：求解器目前仅针对 Kuhn poker 的信息集/动作拓扑实现；接入新博弈需扩展 `games/`。
- **近似误差**：CFR/CFR+ 为近似方法，最终可剥削性非零（随迭代收敛），非精确 oracle。
- **确定性边界**：确定性依赖 `numpy` RNG 设种；若未来引入非确定性后端（如 GPU torch），
  须重新校验 G4。

---

## 伦理与偏见

- 纯数学求解器，无训练数据偏见；不产出任何对人/群体有偏见的预测。
- 仅供研究与教育用途。
